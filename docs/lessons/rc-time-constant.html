NOTE 03 / 基礎電路

RC 時間常數：電容充電為什麼越來越慢？

由零電壓電容的充電過程認識時間常數，將電阻與電容換成正確單位，利用一倍與五倍時間常數估計充電進度，理解指數曲線的意義。

入門約 8 分鐘#RC電路#電容#時間常數#指數響應
AFTER THIS NOTE

讀完這篇，你可以…

  • 用 τ = RC 計算單一電阻與電容串聯電路的時間常數。
  • 以充電公式求指定時刻的電容電壓。
  • 區分接近最終電壓與數學上完全充飽。
01

先限定模型與初始條件

考慮理想直流電壓 Vs 經正值電阻 R 對電容 C 充電，初始電容電壓為 0 V。剛接通時電阻兩端電壓最大；隨著電容電壓升高，電流變小，充電速度便逐漸放慢。

Vc(t) = Vs × (1 − exp(−t / τ))，t ≥ 0
02

時間常數決定快慢

這個簡單串聯電路的時間常數為 τ = RC。若 R = 10 kΩ、C = 100 μF，先換成 10000 Ω 與 0.0001 F，可得 τ = 1 s。電阻或電容增大，充電曲線沿時間軸拉長。

τ = RC；1 μF = 0.000001 F
03

一倍與五倍時間常數

t = τ 時，充電達最終電壓約 63.2%；t = 5τ 時約為 99.3%。五倍時間常數只是常用的近似充飽標準，理想指數曲線在有限時間不會精確等於 Vs。複雜電路則需使用電容所見的等效電阻。

Vc(τ) ≈ 0.6321 × Vs；Vc(5τ) ≈ 0.9933 × Vs
TRY IT YOURSELF

互動實驗室

移動滑桿，觀察數值之間的關係。

模型假設：初始電壓為 0、理想電容充電，輸入電壓階躍為 5 V。
PAY ATTENTION

容易接錯的觀念

  • τ 的單位是秒；不要省略 kΩ 與 μF 的倍率。
  • 本頁充電公式假設初始電容電壓為 0 V。
  • 5τ 表示接近最終值，並非精確到達 100%。
ONE SMALL CHALLENGE

換你算算看

Vs = 5 V、R = 20 kΩ、C = 50 μF，初始電容電壓為 0 V。時間常數是多少？充電 1 s 後的電容電壓約是多少？

提示：先算 20000 × 0.00005；再確認 1 s 是幾倍時間常數。

展開解題步驟

τ = 20000 × 0.00005 = 1 s。t = τ，所以 Vc = 5 × (1 − exp(−1)) ≈ 3.1606 V。
