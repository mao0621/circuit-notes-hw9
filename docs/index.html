歐姆定律：把電壓、電流與電阻連起來

從單一電阻電路出發，理解電壓、電流與電阻的關係，練習將毫安培與千歐姆換成基本單位，再用功率判斷計算結果是否合理。

分壓器：為什麼接上負載後電壓會下降？

用兩顆電阻建立分壓器，先計算未接負載時的輸出，再將負載與下臂電阻合併，觀察相同的電阻比例為什麼不保證相同的實際輸出。

#分壓器#串並聯#負載效應

基礎電路 · 入門

RC 時間常數：電容充電為什麼越來越慢？

由零電壓電容的充電過程認識時間常數，將電阻與電容換成正確單位，利用一倍與五倍時間常數估計充電進度，理解指數曲線的意義。

#RC電路#電容#時間常數#指數響應
